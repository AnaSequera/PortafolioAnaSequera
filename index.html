01 Lo que he construido
Pipeline Zoom → YouTube → Moodle completado

ProblemaCada grabación de mentoría había que descargarla, subirla a mano y publicarla en la plataforma de formación — un proceso manual y lento, repetido decenas de veces por edición.

SoluciónAutomatización end-to-end en n8n: toma la grabación de Zoom, pasa por un flujo de aprobación por email (publicar/descartar) y la deja lista para publicarse — sin intervención manual. Migré el pipeline completo de un proveedor de video a otro en un día, incluyendo diagnóstico y arreglo de fallos de autenticación OAuth2 y de encoding.

n8n Zoom API YouTube API Google Sheets API OAuth2
Detección automática de subvenciones completado

ProblemaEl equipo revisaba manualmente convocatorias de subvenciones dispersas en varias fuentes, y la automatización anterior (en Make) se quedó sin créditos y dejó de funcionar.

SoluciónMigré la automatización a n8n: rastrea convocatorias (BDNS + RSS), las clasifica con un modelo de IA contra criterios reales de negocio (importe, cofinanciación, temática) y entrega solo lo que de verdad califica — con newsletter diario automático al equipo.

n8n OpenAI API API pública BDNS Clasificación con LLM
Dashboard de autoinscripción a mentorías completado

Problema~900 personas necesitaban elegir entre ~32 grupos de mentoría con cupos limitados, sin un sistema que evitara duplicados ni diera visibilidad de plazas disponibles en tiempo real.

SoluciónDiseñé y construí desde cero una plataforma de reserva con panel de administración, exportación directa al formato de matriculación de Moodle, y envío masivo integrado con WhatsApp (WOZTELL) y email como respaldo. Migrada a Cloudflare Workers + D1 para eliminar los límites de una cuenta personal.

Cloudflare Workers D1 (SQL) WOZTELL / WhatsApp API Acumbamail API

Limpiador de bases de datos de contacto completado

ProblemaLos envíos masivos de email dependían por completo de un servicio de pago para validar contactos, y aun así llegaban muchos rebotes que dañaban la reputación del dominio.

SoluciónHerramienta propia en Python con verificación SMTP en paralelo (de 2-5 seg/email a 0.1-0.3 seg/email), validada contra una herramienta de referencia con 100% de precisión en los descartes. Procesa cientos de listas de contacto reales cada semana.

De formulario a PDF firmable, automático completado

ProblemaCada solicitud recibida por formulario requería que alguien la leyera, generara el documento correspondiente a mano y lo enviara por email — tiempo perdido en tareas repetitivas de bajo valor.
